\chapter{基于视觉文本化图像提示的开放词汇检测方法}

\section{引言}
目标检测方法通常依赖大规模标注数据\cite{redmon2016you,ren2016faster}，在稀缺场景（如长尾类别、专业领域与医学影像）中往往难以获取足够标注。因此，少样本目标检测（Few-shot Object Detection, FSOD）\cite{wang2019metadet,Qiao_2021_defrcn2}成为重要研究方向。近年来，视觉语言预训练模型（VLMs）通过海量图文对学习具有较强泛化能力的跨模态表示，这启发广大研究无监督方法的科研工作者可以“以文本提示进行零样本迁移”。然而，医学图像与专业领域的下游任务仍存在三类典型困难：其一，下游类别在预训练语料中覆盖不足；其二，文本提示的描述粒度有限，容易产生语义偏置与遗漏；其三，细粒度目标往往共享相近的文本描述，仅靠文本难以区分\cite{xu2023mqdet,du2022learning}。

目标级视觉语言模型（Object-level Vision-Language Models, OVLMs）\cite{li2022glip,dou2022fiber,liu2023groundingdino,minderer2022owlvit,ma2022hierkd}以 GLIP\cite{li2022glip} 为代表，利用 grounding 数据与多尺度/多阶段跨注意力结构建立了更强的\textbf{目标级图文对齐}，在零样本检测中显著优于 CLIP\cite{radford2021clip} 等图像级 VLM。然而，如何在\textbf{不破坏 OVLM 预训练的图文对齐}前提下，把下游任务中少量支持样本（support images）所包含的视觉语义注入到提示推理过程，仍然是一个关键难题。
现有基于 VLM 的 FSOD 方法通常通过\textbf{微调原模型权重}或\textbf{引入额外可学习结构}来利用支持图像信息，但在少量目标域数据下，这两类做法都可能导致原有的目标--文本相似度分布发生偏移，从而损害源域对齐并削弱泛化能力。更进一步地，许多 OVLM（如 GLIP 与 GroundingDINO）本质上是\textbf{“仅支持文本提示”的模型}，由于结构设计限制，缺少对图像提示（image prompting）的原生支持\cite{li2022glip,liu2023groundingdino}。

图像提示为解决上述问题提供了一条思路：用支持图像作为提示，与文本提示一起为下游推理提供语义引导\cite{luddecke2022clipseg,xu2023mqdet}。然而，现有代表方法 MQ-Det\cite{xu2023mqdet} 通过在文本编码器内部额外引入可学习跨注意力模块来实现“图像调制文本”，它主要对现有文本 token 进行重加权，而非直接引入新的视觉信息；同时，新引入的结构也可能进一步偏置 OVLM 的预训练对齐。

基于此，本章提出 VisTex-OVLM：通过\textbf{视觉文本化（visual textualization）}将支持图像投影到 OVLM 的\textbf{文本特征空间}，把支持样本以“文本 token”的形式直接并入提示序列，从而在不修改 OVLM 主体结构的前提下实现\textbf{直接图像提示}。

\section{视觉文本化图像提示方法}
\subsection{任务定义与符号说明}
在经典 FSOD 设置中，存在基类数据集 $D_b$（类别集合 $C_b$）与新类数据集 $D_n$（类别集合 $C_n$），满足 $C_b\cap C_n=\emptyset$。在新类集合中，每个类别仅提供至多 $K$ 个带框标注实例（$K$-shot）。测试阶段中，提供少量标注的图像称为支持图像（support images），待预测的图像称为查询图像（query images）。在更一般的 GFSOD 设置中，测试类别集合为 $C_b\cup C_n$，要求模型在新类上提升的同时保持基类性能。

对 OVLM 的多尺度/多阶段编码过程，记第 $i$ 个 stage 的中间视觉特征与文本特征分别为 $R^i$ 与 $P^i$，其中 $i=0,1,\ldots,L$。多尺度特征记为 $R^i=\left[R^{i,(j)}\right]_{j=0}^{M-1}$，其中 $M$ 表示尺度数。

\subsection{总体框架}
图 \ref{fig:vistex_framework} 给出了 VisTex-OVLM 的整体流程。其核心由两部分组成：\textbf{多尺度视觉文本化模块（Multi-scale Textualizing Blocks, MSTB）}与\textbf{多阶段融合策略（Multi-stage Fusion, MSF）}。二者共同将支持图像映射为一个或多个\textbf{视觉文本化 token}，并与常规文本提示 token 拼接后直接输入\textbf{冻结的} OVLM，实现无需改动主干结构的图像提示推理。

\subsection{图像提示工程（Image Prompt Engineering）}
由于检测属于密集预测任务，支持图像中同时包含目标、背景及其它干扰物体。为最大化利用少样本标注，本章采用图像提示工程：结合支持图像中的目标框信息，对框外区域进行模糊化处理，使得支持图像更聚焦于目标实例\cite{luddecke2022clipseg}。

\subsection{多尺度视觉文本化（MSTB）}
给定提示工程后的支持图像 $x_S$，使用冻结的 OVLM 视觉编码器提取各 stage 的多尺度特征 $R^i_S=\left[R_S^{i,(j)}\right]_{j=0}^{M-1}$。MSTB 的目标是将不同尺度的视觉特征统一聚合，并映射到文本特征维度，从而得到 stage 级的视觉文本化特征 $\widetilde{P^i_S}$。

为高效共享跨尺度知识并降低训练成本，MSTB 采用参数共享策略：对除最小尺度以外的各尺度特征使用共享的下采样卷积逐级压缩到同一空间分辨率，拼接后再用 MLP 映射到文本空间，形式化为：
\begin{equation}
\begin{aligned}
    \widetilde{R^{i,(j)}_S} = \left\{
    \begin{array}{ll}
    \left( \prod_{j}^{M-2} \operatorname{Conv}_{\text{down}}^{i,(j)}\right) \left( R^{i,(j)}_S \right), & \text{if } j \neq M-1 \\
    R^{i,(j)}_S, & \text{if } j = M-1
    \end{array}
    \right.
\end{aligned}
\label{eq:vistex_downsample}
\end{equation}
\begin{equation}
    \widetilde{R^i_S} = \left[ \widetilde{R^{i,(j)}_S} \right]_{j=0}^{M-1},
\label{eq:vistex_concat}
\end{equation}
\begin{equation}
    \widetilde{P^i_S} = \operatorname{MLP}^i \left( \widetilde{R^i_S} \right).
\label{eq:vistex_mlp}
\end{equation}

\subsection{多阶段融合（MSF）}
OVLM 的多阶段编码对应着多阶段的跨模态对齐过程。为充分利用这种对齐先验，本章进一步对各 stage 的 $\widetilde{P^i_S}$ 进行非参数融合，得到最终的视觉文本化 token $\widetilde{P_S}$：
\begin{equation}
    \widetilde{P_S} = \operatorname{MSF} \left( \{ \widetilde{P^i_S}\}_{i=0}^L \right).
\label{eq:vistex_msf}
\end{equation}
由于 MSF 采用非参数操作（如跨 stage 的 max pooling），因此在不引入额外参数的情况下即可利用 OVLM 的多阶段对齐能力。

\subsection{直接支持图像提示（Direct Image Prompting）}
得到 $\widetilde{P_S}$ 后，将其与文本提示 $t$ 经 BERT 编码得到的 token 直接拼接，构成输入 OVLM 的提示序列：
\begin{equation}
    P^0 = \left[ \operatorname{BERT}\left(t\right), \widetilde{P_S} \right].
\label{eq:vistex_prompt_1shot}
\end{equation}
对于 $K$-shot 设置，为保持每个 shot 的独立性，直接拼接多个视觉文本化 token：
\begin{equation}
    P^0 = \left[ \operatorname{BERT}\left(t\right), \widetilde{P_{S_1}}, \cdots, \widetilde{P_{S_K}} \right].
\label{eq:vistex_prompt_kshot}
\end{equation}
在训练阶段，仅更新 MSTB 的参数，OVLM 主体保持冻结；训练完成后，MSTB 可直接对新类支持样本进行视觉文本化，从而在不微调 OVLM 的条件下完成少样本检测。

\section{实验设置}

\subsection{数据集与任务划分}
本章实验由三层评价组成：经典少样本检测基准用于检验方法在受控类别划分下的有效性，开放集与长尾基准用于检验跨任务泛化能力，医学数据集用于检验从自然图像到非自然成像域的迁移稳定性。所有实验均遵循“源域训练、目标域少量支持、目标测试集仅用于评价”的原则；除专门标注的支持集适配实验外，不使用目标测试图像或其标注更新模型参数。

\textbf{PASCAL VOC。} PASCAL VOC 由 VOC2007 和 VOC2012 两个版本构成，共包含 20 个常见目标类别\cite{everingham2010pascalvoc}。本章遵循标准 FSOD 协议\cite{wang2020frustratingly,zhang2022metaDETR1}，采用三个互不相同的 novel split。每个 split 均将 20 类划分为 15 个基类 $C_b$ 与 5 个新类 $C_n$，以 VOC2007/2012 的 trainval 图像构造训练与支持集合，并在 VOC2007 test 上评价。三个 split 能减弱单次类别划分带来的偶然性：某一类别在一个 split 中作为 novel 类时可能具有较大的外观变化，而在另一个 split 中则由其他类别承担这一角色。实验分别报告 1、2、3、5 和 10-shot 结果，主要指标为 novel 类 AP50。

\textbf{MSCOCO。} MSCOCO 包含 80 个类别和更复杂的遮挡、尺度及背景组合\cite{lin2014microsoftCOCO}。按照通行划分，将与 PASCAL VOC 重合的 20 类作为 novel 类，其余 60 类作为 base 类；训练阶段使用 base 类数据学习视觉文本化映射，评价阶段在包含 base 与 novel 类的 COCO minival 上报告结果。少样本设置采用 1、2、3、5、10 和 30-shot。该划分比 VOC 更具挑战性，一方面 novel 类数量由 5 增至 20，另一方面同一图像中常同时出现 base 与 novel 实例，因此能够同时观察新类适配和旧类保持能力。

\textbf{LVIS 与 ODinW。} LVIS 具有超过一千个实例类别及显著的长尾分布，类别按训练实例频次划分为 rare、common 与 frequent\cite{gupta2019lvis}。本章采用 LVIS MiniVal 测量大词汇量和低频类别上的迁移能力，除总体 AP 外重点关注 rare 类 AP。ODinW 是面向真实下游任务的跨数据集检测基准，各子集均转换为 COCO 检测格式，覆盖水下生物、无人机航拍、手部、蘑菇、包裹、道路坑洞、热成像和交通工具等显著不同的场景\cite{li2022odinw}。定量开放集实验选取 ODinW35 中 GLIP-L 零样本 mAP 不高于 2 的 11 个困难子集，以减少预训练类别重合带来的虚高；定性分析进一步使用 ODinW13 的 13 个代表性任务，观察相同方法在不同尺度、背景密度和成像模态下的误检与漏检规律。

\textbf{医学图像数据。} 医学迁移实验同时覆盖 H\&E 病理图像与 CT 图像。MoNuSeg 由 30 张 $1000\times1000$ 的多器官病理图像组成，按照原始协议使用 16 张训练图像和 14 张测试图像，任务为细胞核检测或实例分割\cite{kumar2017dataset}。CoNSeP 包含从结直肠腺癌 WSI 中截取的 41 张 $1000\times1000$ H\&E 图像，采用 26/1/14 的训练、验证和测试划分，并提供多类细胞核标注\cite{graham2019hover}。这两类病理数据具有细胞密集、前景尺度小、类别间形态接近等特点，与 COCO 自然图像存在明显域差异。LIDC-IDRI 收集 1,018 例胸部 CT 检查，并由最多四名胸部放射科医师通过两阶段阅片过程标注肺结节\cite{armato2004lungLIDC}；DeepLesion 则从临床 PACS 标记中整理出 32,735 个病灶，覆盖 32,120 张 CT 切片、10,594 次检查和 4,427 名患者，病灶类型与解剖位置更加多样\cite{yan2017deeplesion}。在这两类 CT 数据上，支持框描述的是结节或通用病灶，而非自然图像物体，用于检验视觉文本化能否跨越纹理、灰度和目标尺度的联合偏移。

\textbf{域偏移组织方式。} 对开放集和医学域实验，源模型在 MSCOCO base 集上训练，目标数据集整体视为 novel 任务。每个目标类别只从其训练划分抽取 $K$ 个带框实例形成支持集，目标验证/测试划分仅作为查询集。正文中的“直接迁移”表示冻结源模型和视觉文本化模块，仅将支持图像映射为 token 后推理；“2-shot 适配”表示只在明确标注的两张支持图像上短暂更新 MSTB，主干视觉语言模型仍保持冻结。两种口径分别回答“无需目标域更新能否工作”和“极少量适配能否快速恢复性能”，结果表格中不混合统计。

\subsection{数据预处理与支持集抽样}
支持集按照类别而非整图数量进行抽样：$K$-shot 表示每个类别至多提供 $K$ 个标注实例。当一张图像含有多个类别时，仅将与当前支持类别对应的框用于构造前景区域，避免把共现类别误当作提示目标。为保证横向比较公平，所有方法在同一 split、shot 和随机种子下读取完全相同的支持图像及实例框；每个设置采用三个固定随机种子重复抽样并报告均值与标准差。测试期间支持集合固定，不根据查询图像的预测结果重新挑选“更容易”的样本。

自然图像保持原始纵横比并按检测器的尺度规则缩放。病理图像先按固定窗口裁剪为 patch，再移除大面积空白区域；CT 图像采用一致的灰度窗和归一化范围。支持实例的框被用于区分前景与背景，但不把目标测试集标注输入模型。对于图像提示工程，默认采用背景弱化策略：保留框内原始像素，对框外区域施加 0.1 强度阴影及核大小 15、标准差 3 的高斯模糊。该方式既突出目标，又保留少量上下文；相比只裁剪目标，它能避免丢失尺度和邻域信息，相比绘制红色轮廓则不会覆盖原始纹理。

\subsection{提示构造与实现细节}
每个查询类别首先以类别名称构造文本提示，文本编码器将其映射为类别语义锚点；随后，支持图像经过冻结的视觉编码器得到多尺度特征，MSTB 将这些特征投影到语言特征维度并生成视觉文本化 token。最终提示序列由“文本 token + 支持视觉 token”拼接而成。文本提示负责说明“检测什么”，视觉 token 负责补充“目标在当前数据域中长什么样”，两者不能相互替代。多 shot 条件下保留各支持样本的独立 token 后再拼接，避免简单平均掩盖姿态、尺度和染色差异。

主实验采用预训练 GLIP-L 作为 OVLM 骨架，并以 GroundingDINO-T 验证模块的可迁移性。GLIP-L 中 $H=W=100$、多尺度层数 $M=5$；MSTB 的映射器由两层“全连接层 + ReLU”构成，依次完成空间聚合和从图像通道维度到文本通道维度的转换。MSTB 默认接入 GLIP-L 的 8 个图文交互阶段，阶段间采用无参数最大池化完成 MSF。训练 MSTB 时冻结原有 OVLM 参数，在 base 数据上每轮为每类随机选取 $K$ 个支持实例，其余图像作为 query；采用 AdamW 优化 30 个 epoch，初始学习率为 $10^{-4}$，权重衰减为 0.01。该设置把新增学习能力限制在视觉文本化映射上，便于区分“提示适配增益”与“整体模型重训练增益”。

\subsection{评价指标与选择依据}
经典 VOC 少样本实验报告 AP50，即在交并比阈值 $mathrm{IoU}=0.5$ 下对精确率--召回率曲线积分。该指标对定位误差具有一定容忍度，适合观察极少样本条件下类别是否被正确发现。MSCOCO 与开放集实验报告 AP 或 mAP，即在 $mathrm{IoU}=0.50:0.05:0.95$ 的十个阈值上平均，因而同时考察类别判别和边界定位精度\cite{lin2014microsoftCOCO}。需要强调的是，AP 是按类别分别计算再取宏平均，样本量大的类别不会直接淹没低频类别。

在广义少样本检测（GFSOD）中，同时报告总体 AP、基类 AP（bAP）和新类 AP（nAP）。总体 AP 反映部署时 base 与 novel 类共同出现的综合表现；bAP 用于检查少样本适配是否造成灾难性遗忘；nAP 则直接衡量模型从支持样本获得的新类泛化能力。若只报告总体 AP，较高的 base 类分数可能掩盖 novel 类几乎没有改善；若只报告 nAP，又可能忽略模型通过过拟合支持集换取新类分数、同时破坏原有知识的问题。因此，AP、bAP 与 nAP 的联合报告是判断视觉文本化是否真正“增加新知识而不破坏旧对齐”的必要条件\cite{wang2020frustratingly,zhang2022metaDETR1}。

对于 LVIS，另报告稀有类别 AP（APr），用于观察长尾低频类别是否从视觉提示中获得更大收益\cite{gupta2019lvis}。医学单图分析和可视化补充报告精确率、召回率与 F1：精确率反映误检控制，召回率反映小目标或密集目标的漏检程度，F1 是二者的调和平均。由于不同数据集的类别数、目标密度和标注粒度不同，跨数据集时不直接比较绝对 AP 高低，而重点比较同一数据集、同一支持集和同一评价脚本下相对于 GLIP-ZS 及其他基线的增量。

\subsection{医学域支持图像提示的增益与消融}

这些现象说明，视觉文本化的主要作用是改善支持实例与查询目标之间的对齐，而不是替代候选框生成、尺度建模和数据质量控制。失败案例与图~\ref{fig:vistex_odinw} 的跨域规律相互印证：当目标轮廓清晰且支持样本具有代表性时，视觉 token 能稳定降低漏检；当目标极小、成像模态变化显著或支持背景具有强偏差时，增益会减弱。因而实验报告必须同时记录支持图像选择规则、shot 数、随机种子及不同种子间波动，不能只报告一个未说明抽样过程的最高分。后续可通过支持样本质量评分、跨 shot 去冗余和不确定性加权进一步减轻上述问题。

\section{本章小结}
本章提出 VisTex-OVLM，通过视觉文本化将支持图像投影到 OVLM 的文本特征空间，使图像提示能够在不改动 OVLM 主体结构的情况下参与提示推理。借助 MSTB 的多尺度映射与 MSF 的多阶段融合，VisTex-OVLM 在标准少样本基准与开放集迁移设置中均取得了显著提升，验证了“以图像补充文本语义、且保持预训练图文对齐”的有效性。
视觉文本化的收益依赖支持样本是否覆盖目标的尺度、姿态、染色和局部上下文变化。若支持样本包含错误框、严重遮挡或非代表性背景，视觉 token 也可能把偏差写入提示序列；当新类与基类形态高度相似时，少量支持图像仍不足以完全消除类别混淆。因此，部署时应固定并报告支持集抽样规则、shot 数与随机种子，同时结合置信度校准和支持样本质量筛选。
